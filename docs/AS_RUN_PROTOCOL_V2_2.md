## 模型、资源与预算

所有实验语言/视觉调用使用原 Codex CLI 0.163.0，帮助和参数见 configs。A 重建使用 gpt-6.1-sol medium；C 的共同图像定位与双方共享程序修改使用 gpt-6-astra medium。每次新 CLI 会话仅看到所需提示和真实暂存图像附件；禁用网页和子代理等工具，权限沿用原只读适配设置，没有更改全局登录、安全配置或调用独立模型 API。

请求模型与可确认的实际返回模型分别保存；没有返回路由证据时 unknown/null，不能用自称或请求名证明路由。CLI 会话数、可观测 CLI turn、未知底层推理轮数、usage 与工具调用分开。缺少 usage 不补 token 或费用。

CPU 两计算线程、单个重任务，CUDA_VISIBLE_DEVICES 为空。未发现调度分配，nvidia-smi 驱动查询失败，未使用或修复 GPU。复用原 Python3.11 环境、Blender4.2.10和本地 LPIPS/DINO/AlexNet；没有安装/升级共享环境或下载权重。

整轮上限180个新 CLI 会话、600个渲染帧口径；真实消耗见 `ledger.json`、`metrics/calls.csv`。失败调用、恢复检查、探测和无效程序均计入。渲染预算沿用 `build.py` 执行尝试加各 render_ledger 的上界，另报真正完成帧。CLI 内部重连不算新增会话，底层是否发起模型请求不可据此推测。

## A：固定 H 的新来源重复测试

6个新 Commons 来源页面，各2次模型随机重复，各运行H0和r1/C2，共24次；按冻结顺序交错。6个来源是统计场景，12个随机重复不是12个独立场景。页面ID未命中已检查的旧收集/实验记录；本轮执行前人工适用性接触检查公开保留，不宣称严格盲测或排除所有历史/模型预训练暴露。每物理来源只选一视角，来源和许可见 manifest、data/ATTRIBUTION.md。

每任务3次CLI、2次Blender执行、600秒内层总预算；正式等比缩放长边512，CPU Cycles16 samples、seed42、AgX、相同颜色管理。远端随机采样种子不可固定；渲染seed不等于远端模型或所有生成程序随机性均被控制。没有为CPU降低正式质量。

沿用 Q=(clip(SSIM,0,1)+1-clip(LPIPS,0,1)+(1+clip(DINO,-1,1))/2)/3，PSNR另报。指标来自本地真实数值前向。失败原始Q/PSNR/SSIM/LPIPS/DINO为null。独立执行效用为Q（执行有效）或0（失败），必要功能通过率另报；不把该零值写回测量字段。

报告全部24任务、双方成功配对、成功条件质量及固定失败分母效用。功能 required/applicable/measured_pass/gate_pass 沿用冻结规则：结构/材质检查必需，预先标记的家具场景另要求组合/声明部件。必需缺测不通过。成功率提高不等于成功条件视觉质量或条件编辑能力提高。

A 无新 Selection 或候选搜索：r1/C2 由旧V2.1选择后固定，新测试不修改H。A只验证此固定发现，不证明RSI搜索优于其他框架，不能把收益归因于三维诊断或单独复杂度规则。

## B/C：工程修复与实际机制比较

先完成零模型机制验收：明确预算、真实目标ID、实际观测进入第二阶段并改变决策、9类阶段分类/unknown、服务失败不假定几何、回归选择真正生效；另实际运行8种正确/损坏几何编辑夹具及一次64×64/1sample指定Z对象探测，后者排除正式结果。见 tests/MECHANISM_ACCEPTANCE.json 和 calibration.json。

C用10个新参数化SceneAct房间，5类故障×2配置，来自两种模板，不称10个独立自然房间。构造时预写真实对象、故障API模块、精确/宽泛相关允许集合；只供评价器，未发送给M。M看到共同图像、真实对象/投影、公共受损helper程序及工具结果。

控制组保留真实V2.1 M0代码，公共视觉采集器统一为V2.2格式。每例只有一个共同astra定位会话，结果原样给双方。因此这是相同结构化视觉证据下的M程序比较，不能冒称完整原生V2.1端到端重跑。

双方各最多2个实际Blender探测和3个M选择的研发回归；然后真实观测进入 `M.plan_patch` 再决定共享模块。新M比较事前预测方向与实际受控响应及直接结构/编辑事实，不按最大Q增量择因；相同/未知预测保留unresolved。隔离只用可见性/成员事实，不将全图Q解释为遗漏的唯一原因。探测保存真实修改后的probe_scene.blend，原始提交不覆盖。

每组每例同一个受损共享H、同一个astra medium编码模型、1次编码机会，无无效程序补救。编码器均可修任意helper函数，包括M错误或unresolved时。固定6项最终API/结构/编辑行为在源场景和改变参数、几何、名称、共享数据的迁移场景执行；M不能关闭最终不利检查。对应程序、diff与实际结果保留。

显式API契约给编码器很强提示，可能出现双方全修复的天花板。helper H是辅助控制环境的共享变换程序，不是自然图像重建H；迁移只支持有限参数/所有权结构泛化，不等于自然场景恢复或M元能力提高。

精确模块、宽泛相关模块、对象top1（相机N/A）、探测执行、事前预测方向区分、真实修复与迁移分别报告。实际观测与空观测的同M确定性回放只检查决策依赖，零新增模型/探测，不是MetaImp。

共同视觉会话实际10次，双方各看到10次；成本分摊时各记一半，不将实际10次写成20次。编码最多20次。共同工具、调用机会与上限相同不表示实际token、渲染数完全相同，均逐组公开。

修改后的旧定位只标历史；保留当前对象清单、源码diff和新回归。本轮无修改后新视觉定位，不把旧映射当当前事实；diff关键词只作近似风险提示。

## 偏离、失败和结论边界

A两次不同任务发生明确workspace routing故障，两次最小astra真实图像恢复检查成功，原失败未重采样。运行中将恢复细则定为每事件一次、整轮最多3次，属于as-run补充，未扩大样本/180会话上限或修改H。CLI超时另列，不能证明都是服务商故障；构建超时没有细分事件时保持unresolved，不凭build.py存在推断几何原因。

自然图像无三维真值，不报真实3D精度或无尺度依据的米误差。AABB支撑/投影是近似，BVH只测表面交叉且可能包括合理接头。机械材质/组合移动不是文字指令编辑；本轮不新增文字编辑能力结论。生成程序P、固定共享H、工程修改M和自动元自修改严格分开；本轮没有自动M后代。

所有实际新数据、失败、图表源CSV和报告在独立V2.2目录。V1/V2/V2.1保持原样；图表选择规则和原始点见审查索引。测试结果本轮公开后不能再称未来全新盲测。
