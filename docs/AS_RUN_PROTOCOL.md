# Scene-RSI 首轮 as-run protocol

本文件于归档时根据现有文件事后整理，**不是新增预注册**。实际协议及各次冻结/偏离的原始证据在 [实验 protocol.md](../experiments/scene_rsi_pilot/protocol.md)、冻结标记、preuse 目录与源码 diff 中保留。首版冻结在正式开发前；v1.1 补记发生在首个正式任务启动后、首个正式结果前。后续验证器、资源、恢复和独立外部阶段适配不能冒充从一开始就冻结。

## 实际范围与资源

主实验 2 Development / 2 Selection / 4 Test，2 次独立研发 r1/r2，每方法每次最多 K=2 共享 H 候选。默认 4/4/8 的预估仅学生调用已达 880，会超过上限，因此在正式结果前全组等比例缩小。两个开发专用 smoke 永久排除终测，实际 1 成功、1 失败。

总上限 600 个 Codex CLI 会话、1500 次渲染尝试；实际 **596 会话、660 帧完成渲染、715 次尝试上界**。尝试上界包含构建失败，不能称715张完成图。保存594份会话记录，508 complete、86 failed；最初2次初始化失败原始日志被覆盖，已计费且明确未保存，不能重建。已知输入 token 26,027,542、输出1,933,817；87会话 usage未知，费用unknown。CLI会话不等于模型推理轮数；可观察CLI turn594，模型轮数null，工具调用0。

资源始终单重任务、CPU至多2线程。用户后续授权后，GPU0–3仅作为候选池，逐次检查活跃进程/利用率/显存，每次子进程至多一张；繁忙继续CPU。恢复末段全CPU。混合设备和服务等待使wall time不能解释为算法速度优势。本次归档不使用GPU或模型；仅对脱敏副本做少量Blender只读打开，不构建、保存、渲染或终测。

## 共同起点、模型和权限

共同H0为本地SceneEvolve未演化的 `backend/harnesses/baseline/{policy.py,system.txt}`。共同SceneAct、Blender4.2.10、固定外部评价器及功能门槛。所有方法学生/固定编辑器请求 **gpt-6.1-sol/medium**，元提案及独立视觉评审请求 **gpt-6-astra/medium**。这是请求配置，CLI未独立返回可验证实际路由，实际路由unknown。远端模型采样种子未控制；Cycles种子42；不能声称统一控制了所有生成程序的Python随机性。

共同内层上限5次学生调用、3次Blender执行、1200秒；单CLI/Blender600秒。候选外层至多2次teacher调用、每次2400秒；每候选最多2次诊断探测。失败、评审、修复、探测、连接检查全部进入总预算。CLI真实图像附件，新ephemeral会话、read-only、禁模型工具/网页/子代理；候选仅能改允许的policy.py/system.txt/meta.py，不能改指标/数据/预算/资源管理。

## 实际方法与公平性

|方法|实际行为与边界|
|---|---|
|fixed_h0|固定跨图像H；允许共同单任务内层修复。|
|sceneevolve_cli|复用teacher模板和反馈/保留逻辑，CLI/backend适配；原同时两个子代改为最多两次顺序候选，M固定。不是论文原分数。|
|generic_rsi|本地未找到完整Hyperagents；按官方任务程序/元程序/档案映射为H、可执行M.plan(packet)、候选档案。实际M后代参与后续提案并产生可用H，标generic_rsi_cli_adapted；限制文件范围和父代策略使其不等价于官方完整Hyperagents。|
|scene_rsi_pilot|相同H0、原始证据、探测工具及评分；初始M组织诊断记录与回归证据。机制A/B只部分实现，不称已验证创新。|

原始Development参考/代码/渲染/轨迹/指标/结构接口同权，所有方法同探测额度与最终验收。Ours策略会预先用部分额度，其他方法可自主请求；实际调用数因此不保证相同，按原始日志完整报告。Selection仅返回固定聚合值，不给任意原图/程序。候选M收到真实附件范围为开发参考、最终选中渲染及实际探测图；保留中间图不等于模型看过它们。Ours未获得独占强模型或额外隐藏修复。

H0相同源码的终测按同重复/图/配置复用，记录reuse_of和零新增成本；复用不是新的独立样本。主记录88槽：78 complete、6 failed、4因提案拒绝未运行。

## 选择、测试与暴露

所有数据有历史联系表/人工检查暴露，场景独立性只据来源元数据，本轮为exploratory。按来源场景分组，非视频帧随机拆分。原本16条清单中3条预留后来实际用于元回放；本次只公开11条已用主/回放数据，另外5条未用预留数据不公开。公开过的测试和回放结果以后不得称为全新盲测。

Selection先要求成功数、功能全通过数不低于同重复H0，再要求endpoint Q比当前最佳严格增加0.01；平局保留早者，H0始终入池。失败endpoint效用0是选择效用，**不是测得图像分数0**；逐场景缺测保持null。0.01为实用阈值，并非统计显著界限。

主方法所有搜索/选择冻结后才运行有效Test，记录未将其回流同轮开发；服务恢复前没有有效主Test。历史故障后重新冻结选择、验证器误拒绝统一复核等偏离都有原档案。消融沿用了已经见过的主Test，不能称新的盲测。缓存续跑曾重写消融选择时间戳；选择一致，但最早时间戳未独立保留，不能事后补造。

主终测32个逻辑槽27有效、5失败；相对H0有效配对r1各2/4、r2各3/4。SceneEvolve配对Q差r1 +0.02567、r2 +0.05691；Generic +0.02474、0；Ours +0.00983、0。六个完整有效改进标志均false，主要因完整4场配对不齐，不能解释为所有方法质量更差。条件均值不能跨不同有效集合直接比较。

## P、H、M各自真正改变了什么

P是逐场景build.py/scene.py及.blend；内层修复和临时相机/尺度/遮挡probe属于P，不能算新的共享算法。H改动只在候选policy.py/system.txt，并在其他Development/Selection场景重新执行。所有候选代码、rejected_proposal、changes.diff与提案原输出均保留。

M是可执行meta.py，不只是追加历史文字。Generic与Ours存在实际执行过的M后代，`meta_execution.json`、`reports/analysis.json`和`quota_restored_20261103/meta_program_participation.json`记录后代源码、plan及后续提案参与。Ours r1/C1后代用于r1/C2。执行过后代不证明元能力提升。冻结回放让两个M从同一陌生H_start（SceneEvolve r2/C1）开始；未比较不同H起点。

## 评价与真实能力边界

Q沿本地公式：`(clip(SSIM,0,1) + 1-clip(LPIPS,0,1) + (1+clip(DINO,-1,1))/2)/3`；另报PSNR。DINOv2/LPIPS是本地权重真实CPU前向，不是模型估分。完整参考按EXIF/RGB/等比最长边512预处理，不裁剪；正式Cycles16、seed42、AgX/None、exposure0、gamma1，关闭自适应/降噪，CPU/GPU同质量。smoke最长边256排除正式分析。

机械检查包括对象结构非空/有限、目标材质替换的非目标参数保持、组合移动后的部件相对变换保持；只证明已测结构可操作，不能证明语义对象齐全。名字规则可能选到architecture；AABB重叠仅近似候选，不是真实Mesh碰撞。未知尺度归一化；无三维真值，不报告真实3D恢复精度；固定侧/俯视仅检查结构，不证明不可见部分正确。

文字编辑为相同sol固定编辑器读同一蓝色工作台指令、一次调用无修复；16计划、14实际执行、11通过：端到端11/16、条件11/14。2缺原重建，3执行后功能不合格。相机/拓扑/非目标参数检查有共同v2修正和两个预用控制。独立视觉评审27次完成、5因重建缺失未评审，仅补充证据。

机制A实际有焦距×1.1、对象尺度×1.1、隔离目标等固定探测；未知代码/语义映射保留unknown，主动接触干预未实现。机制B执行共同完整三项菜单并用回归证据指导Ours，按修改模块自动选择回归子集未实现。不能把有限敏感性实验写成可靠因果归因。

## 额外阶段与偏离

三消融各1独立研发、K1、同2/2/4：独立生成，不是共享池选优；终测10/12成功、2路由失败。三条件与匹配Ours参考共同有效配对为0，不支持跨条件均值机制收益结论。

冻结M回放按余额采用预声明最小档：一个陌生H、每M一次提案、1dev/1selection/1test，7次物理重建成功；两M候选均未通过Selection增益门槛，均选择共同H_start，Test增益均0。初始M探测2、后代0为其原策略实际行为，未工程救场。只有一个独立测试场景，属于可行性验证，没有普遍元能力结论。

BlenderWorld只用bw_0005与独立后续bw_0011。原外部阶段余额23不足24上界，结果前增加单任务档；第一阶段结束余额12，又在自身结果前按固定条件启动独立bw_0011，分别报告，不能冒充原预注册两任务队列。两方法H来源固定H0与主r1 Selection所选Ours C2，没有按Test胜负重选。

直接读.blend、三固定视角、512/Cycles16、Codex匿名judge，保留原rubric含义/权重和8维度；省略官方盲描述流程、改变视角/分辨率/模型，**adapted evaluation、非官方榜单**，不执行官方打包哈希入口。适配分数为二值rubric百分比与8维平均×10的均值。bw_0005 H0/Ours Q=0.28543/0.31289，H0评审路由失败，Ours54.7222；bw_0011 H0程序失败、Ours Q=0.48763/功能通过，但评审路由失败。两任务均没有完整适配评分配对。bw_0005完整参考含文字/人物拼贴，全图Q有额外局限。

集中路由/额度故障、用户通知额度恢复后的统一续接、两个共同验证器误拒绝修正均保留旧记录；48次历史物理重建失败仍单列。最后一次队列退出码0仅表示流程收尾，不表示任务全成功。更大冻结回放、完整A/B、严格新盲测、转台视频未完成。本次只归档现有产物，不重采样、不补测。

## 归档脱敏与可重算性

原实验留在服务器不改；公开副本仅隐藏账户/资源路径（包括.blend中等长替换的账户路径字符串）、5条未用预留数据，省略缓存/权重/环境，详见REDACTIONS.json与DEPENDENCIES.md。源码快照保留实际运行版本及已有历史diff；公开路径标记是脱敏，不是新算法版本。归档新增脚本仅整理/离线重画，不替换实际H/M/评价器。已有2次原始CLI日志损失如实保留unknown。
