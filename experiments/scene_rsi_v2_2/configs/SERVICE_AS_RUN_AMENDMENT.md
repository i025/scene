# 服务故障处理细化（非执行前预注册）

A 原冻结后发生两次不同正式任务的 workspace routing discovery failed，另有一次 CLI 超时。第一次最小恢复检查成功，原失败任务没有重采样。
第二次路由事件后细化：每个不同事件最多一次最小恢复检查，整轮最多3次；检查失败立即停止后续模型提交，不循环轮询。全部计入原180会话，使用原reserve，不扩大总上限。
这项服务处理细则是在运行中增加，明确属于 as-run 修订。24个正式任务、H版本、模型/effort、内层预算、原始失败记录和评价公式均不改变。
恢复检查不作为重建或算法改进结果，不把 CLI 内部 reconnect 次数当作独立模型调用。
