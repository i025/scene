# Scene-RSI V3：正式运行前冻结协议

本文件在 V3 正式 round0 和十轮开始前保存。准备阶段已经完成的 smoke、工程修复、功能夹具及评价器校准是 as-run preparation，见 preparation/，不追称预注册实验。冻结时间、实测准备消耗和平台快照由 configs/freeze.json 记录；不做内容哈希。

## 起点、模型和资源

固定 H_start 为 V2.1 r1/C2 实际 policy.py/system.txt，经 V2.4 fixed_h/r1_C2 继承，保存为 fixed_h/historical_r1_C2_start。它不是 original_H0，也不是本轮训练后选择的起点。新模型、预算和评分下重新运行，旧产物不当作公平基线。M000 为本轮工程实现 initial_m，包含准备阶段 Astra 写出并在两张开发图执行过的 projected_parts 动作；该动作不算正式演化后代。

H 与固定文字编辑器：用户明确选择 gpt-6.1-terra；M 研究/共享 H 编码及独立评审：gpt-6-astra；全部 medium，Codex CLI 0.163.0。真实 --image 附件、独立 ephemeral 会话、read-only、项目说明读取关闭，shell/web/MCP/子代理等工具关闭。只保存 CLI 可见事件，不以 turn 数冒充底层请求。requested_model 与 observed_model 分开，后者无元数据为 unknown。价格、精确请求数及服务排队无法确认；不宣称 Terra 已实际降低账单。准备期间 Sol/Terra 联通短暂并发的偏离保存在 amendments 中；正式 max_cli_concurrency=1。

用户授权 8 CPU、32 GB。冻结 CPU-only、1 个 Blender 工作进程×8 线程，指标任务×8 线程，重任务不并发，CUDA_VISIBLE_DEVICES 为空。相同场景 2/4/8 线程实测 12.276/6.335/4.188 秒，选择 1×8。launcher 将实验树绑到获准的 8 个 CPU，监测本实验进程树内存，32 GB 上限；不管理其他用户进程。RSS 是采样下界，不是完美峰值。正式中不静默切换 GPU 或渲染质量。

## 数据、隔离和暴露

manifest.json 明确列出 12 development、4 selection、6 test、2 meta_replay 来源；configs/data_exposure.csv 记录历史访问。按来源 ID/group/解析后的媒体路径检查，没有使用哈希。开发图均为历史照片，旧测试转开发后永久标记暴露。BW 的本项目划分是自定义研究划分；bw_0005/0011 有历史运行，其他来源也不能证明从未人工查看，整轮为 exploratory，不宣称严格盲测和完全地点独立性。

每轮固定轮转观察 4 张不同开发图，前 3 轮覆盖 12 张。H 变更后生成当前版本证据，相同 H/配置引用已有产物并明确 reuse。M 获得真实参考/渲染、Q、功能、实际 P 与执行轨迹、对象清单/投影和 H/M 源码；没有 .blend 则研究代码/失败轨迹，不假装几何探测。Selection 逐图结果、rubric 和数据根目录不进入 M；只提供归档聚合。Test 在十轮和最终选择冻结之前完全不运行、不反馈。

## 开放研究与候选

实际执行当前 M 的 research(context, api)。它可在每轮 4 个 Astra 会话、16 帧额外诊断、7200 活动秒内迭代观察—设计/选择动作—执行—再决策—停止/提案，不要求用满。可新增参数化 actions/*.py 或 H/M Python 辅助模块；runner 不固定五选一。只允许公共 SceneAct/Blender 测量操作，文件、网络、模型调用、直接渲染/保存由固定平台控制。每次动作在原 .blend 的独立进程副本执行，保留目标、预期、测量、真实渲染和后续决策。投影/射线/敏感性不是唯一因果证明。

每轮仅一个主要候选，失败、拒绝或 unchanged 均占本轮，不补采样至成功。H-only、M-only、H+M 分别追踪。M 可执行并真实进入后续轮次才能称参与探索，不能称能力提高。H 拒绝不强制丢掉有效 M；M 无效也不否定独立有效 H。不变代码不是后代；未被入口引用/执行的新 H 文件不能算 H 改进。新增/修改动作须有实际执行证据，跨场景复用单独记录，不以数量奖励。

外层工程师只在准备阶段实现平台和 M000；正式阶段不修候选、不提供额外研发意见。固定平台错误须暂停、保留旧记录、说明影响和公平重跑，不无痕改分。

## H 和总预算

H 每场活动墙钟 3600 秒，单 CLI≤900、构建≤1200、单渲染≤600；最多 4 H CLI、3 构建执行，后续 CLI 请求前检查是否还有执行机会，保留 900 秒用于修复/交付。少用少计。外部 BW 评分独立于 H 预算，计入总成本。无远端采样种子保证；本地顺序、程序和渲染 seed=42。

全轮硬上限：1200 新 CLI 会话、3000 渲染尝试、4000 万可见输入 token、300 万可见输出 token，包含准备、失败和重试。usage 缺失保持 null 并报告覆盖率，未观测调用不能按零成本解释。研究阶段只使用上限的 70%，至少 30% 留给最终端点评价/回放；达到上限停机保存，不提高限额追正结果。

真实两次开发 smoke 表明 H_start 完整流程会用 3 个 H 会话，第二 smoke 三次均构建成功；第二图 Q=0.4538156443，preview BW=79.375。复杂场景正式 9 视图 CPU 渲染约 9 分钟，整轮预计需数小时至隔夜，不以混合设备耗时推导算法效率。配置内估算最多 136 次重建、928 会话和约 2300 渲染尝试；token 约 3800 万仅为基于准备日志的预测，不是测量或保证。安全上限实际逐次执行；无法完成必须精确列 pending。

为保留十轮、多图研发、完整 Selection 和终测，独立 development preview BW 仅在全量 H_start/H_best 端点执行；各轮开发仍有真实参考/渲染、Q 和功能证据，不把未执行 BW 填零。Selection/Test 不减质量。语义编辑固定开发子集和指令，每端点最多 1 CLI/1 执行/0 修复，机械与文字编辑分开。

## 三层评价与选择

1. 产物有效：真实 .blend 打开、依赖可用、可渲染；失败、评价失败和 pending 分开。不用平均亮度或三个 Mesh 代替忠实度。
2. BW-style / CLI-adapted：沿用官方 rubric 权重/含义及八维；S_rubric=100×加权二元通过比例，S_dimension=10×八维均值，S_BW=两者平均。官方任务使用配套 rubric；开发 reference_requirements_v1_preformal 在正式结果之前确定。结构条目必须引实际场景数据，视觉条目引真实参考及作者/评价渲染。使用固定八个评价视角+作者视角，Selection/Test 1024×1024、64 samples、Cycles CPU，种子/色彩口径不变；作者视角保留作品宽高比。Development preview=512/16/较少视角，分开绘图。
3. 必要功能：有限非空几何/矩阵、可打开工程、局部材质操作目标成功和非目标保持；场景明确声明的部件依赖完整性作为适用硬约束。组合移动、支撑近似、三角面穿越等保留 required/applicable/measured_pass/gate_pass；无可靠真值的支撑/穿插不强制全部通过。AABB 不是真实碰撞。没有三维真值不报告真实几何恢复精度；机械操作不当作语义编辑通过。

候选资格与排序分开：Selection 固定 4 图全部执行成功、4 图全部可评价且每图必要功能 gate_pass 才有资格。候选绝对要求不因父代失败降低。H_start 始终安全回退。父代有资格时，候选平均 S_BW 至少提高 delta=2.5 才接受，平局保留父代。delta=max(2,准备阶段10产物各两次盲化评审的最大绝对重复差2.5)，不是统计显著性阈值。距离门槛±1 时，父代和候选各所有4图共同追加一次独立评审，使用全部评审均值，不挑高分；失败缺测不能通过。

如果父代确实生成失败或已完整评价但必要功能不合格，而候选达到绝对资格，可按资格恢复保留；此项不称成对视觉提升。父代仅因评审服务缺测不触发资格恢复，仍保留父代并记录评价不充分。生成失败的原始 BW/Q/PSNR 等保持 null，另列端到端效用0；服务失败效用保持 null。瞬时服务/评价失败最多共同规则重试1次；确认路由/配额错误暂停提交，不循环重试。

同一冻结候选的新会话独立评审使用 Astra medium，但仍存在同模型偏差，未执行人工评价。适配替换了官方模型、多代理取景/证据组织与入口，不运行官方打包哈希流程，不与官方榜单分数直接比较。

## 第十轮后

最终 H_best 按 Selection 保留轨迹冻结后，才执行 Final Test。保证 6 来源×H_start/H_best×1 独立生成。完成开发端点/检查点之后、任何 Test 开始之前，若剩余 CLI≥200、渲染尝试≥600、输入≥1100万、输出≥60万，则统一采用全部6来源两个端点各2次；否则统一1次。选择记录 test_repeat_plan.json，不读取 Test 分数，不局部挑第二次。H_start=H_best 时引用同版本产物并记 reuse，不伪装成独立采样。

保存 M000、第5轮和最终有效 M。冻结元回放仅在有真实后代、足够独立任务/陌生起点和预算时执行；否则 pending/未验证，不以 H 曲线冒充元能力提高。本轮不自动第11轮。未运行 Test 为 pending/null，十轮不是十个独立实验，重复按独立来源聚合。
