## 固定学生及权限

复用 V3 的 CLI adapter、Runtime.execute、SceneAct、Blender、进程计量；学生控制流是本轮最小封装，不等同于历史完整 V2 研究平台，不直接加载历史最佳 H 或旧场景。完整源码见 code_snapshots/preformal。

S=gpt-6.1-terra/medium；教师、自修改=gpt-6-astra/medium；Codex 0.163.0。沿用已跑通设置，不做选型、额外收费视觉smoke。首项开发即真实联通验证。requested_model与observed_model分列；后者仅采用CLI元数据，否则unknown。费用不可见，不宣称降本。

每次重建为全新逻辑任务、空场景工作区、独立初始CLI；最多两次主要生成/修订调用和两次构建。第二次CLI也为新会话，显式传本任务当前代码与当前渲染（成功时真实 --image 附件）；不使用隐藏resume。第二次可keep/revise/stop；不使用外部评分选优。首个有效工程/PNG保留不可覆盖steps/NNN；修订失败保留本任务前一成功checkpoint。第二次构建没有第三次学生观察；final_seen_by_student如实记录。成功仅指可打开工程及可读图片，不代表忠实或优质。

CLI只看到匿名暂存附件和提示，shell/MCP/web/子代理/文件工具/历史记忆禁用，read-only、ephemeral、project_doc_max_bytes=0；新学生只拿原图、共同要求、最终语言Hint。观察到内部工具则保存并中止，而不漏计；底层请求/全局系统提示不可完全观测。Blender程序禁止外部文件、模型、渲染和保存；固定后端执行，不加载图片当纹理。

## 教师与一次自修改

M0四个共享纯函数initial_hint/update_hint/compress_hint/self_modify组织调用；可修改代码决定诊断、指导、纠错组织或压缩策略。每次指导最多2个Astra会话（包括服务重试及必要压缩），hint上限1200 Unicode字符；不能直接截断，不接受代码、路径、URL或编码载荷。原始draft/最终Hint/观察/纠错记录/理由全部保留。自然语言约束还将在归档时人工检查，不由外层工程师改写已发出的Hint。

反馈教师只能看本题本教师原图、上次final、已发Hint和有界轨迹：最多10000字符，实际程序摘录最多4000字符、每步错误末尾2000字符。截断标识明确；无有效final时不虚构视觉观察。无几何干预权限。

4项开发终态后，M0.self_modify使用同Astra后端读取自己源码、两题4条真实记录及附件，提交一次完整teacher.py替换或unchanged；只准纯Python标准库与相同4函数接口，可新增纯函数。不能修改学生/模型/预算/数据，不得硬编码场景ID、路径或特定答案。最多一次技术修复（不增加研究候选、不由工程师代写策略）。仅语法/接口/权限检查，不判断质量。无可执行共享变化则停止比较，不凑次数。M1冻结后只参加比较，不生成M2，不改源码后再跑E02。提示策略变化如实标注，不称新三维算法或元能力增强。

## 配额与错误

CPU-only，用户既有8核/32GB授权，固定affinity0–7，单个Blender8线程，各数值库最多8线程，任务串行，进程树32GB上限。继承验证过的单任务3600秒活动墙钟，单CLI900秒、单build1200秒、单render600秒，均受总剩余约束；为修订/交付保留900秒，没有执行余量不再生成代码。模型服务等待不可拆分为纯推理时间；本地排队与实际活动分开。教师/自修改耗时单列。

统一Cycles/CPU、长边768、原宽高比四舍五入、不裁剪、32samples、seed42、AgX/None/exposure0/gamma1、无降噪。最多24张主视角渲染尝试；无额外视角，优先完整12项。服务瞬时错误允许一次重试，且受指导阶段2会话与全局60会话上限；明确路由失败、连接拒绝或额度故障中止提交，保存现场，不无限探测。模型内容失败不得额外采样。60包括教师、学生、自修改、技术修复及全部重试。预计24学生+12指导+1自修改=37会话，压缩/技术修复等上限50，额外有限服务重试也不超60。

中断未完成任务不得从零重抽；保存CLI/步骤状态后按原阶段恢复，不覆盖已有请求/步骤。已终态失败不重试整个重建。resume不启动M2或第三轮指导。
